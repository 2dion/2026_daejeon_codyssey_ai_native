# 나만의 프롬프트 관리

Python 기초 문법과 Git을 학습하기 위한 콘솔 기반 프롬프트 관리 프로그램입니다.

## 실행 방법

Python 3.10 이상이 설치된 환경에서 아래 명령어를 실행합니다.

```bash
python3 main.py
```

이 개발 환경에서는 `python` 명령어 대신 `python3`를 사용합니다.

```text
$ python3 -V
Python 3.14.4
```

## 저장소

- 원격 저장소: [https://github.com/Builter251/A1-1](https://github.com/Builter251/A1-1)

## 기능

- 프롬프트 추가
- 프롬프트 목록 및 카테고리별 조회
- 키워드 검색과 상세 보기
- 즐겨찾기 관리
- 카테고리별 Markdown 파일 내보내기
- 프롬프트 수정·삭제 및 조회수 Top 목록

프롬프트와 즐겨찾기 상태는 `prompts.json` 파일에 자동 저장됩니다. 프로그램을 다시 실행해도 이전 데이터가 유지됩니다.

## 주요 함수

| 함수 | 역할 |
|---|---|
| `show_menu()` | 사용자가 선택할 수 있는 메뉴를 출력합니다. |
| `add_prompt()` | 제목·내용·카테고리를 입력받아 프롬프트를 추가하고 저장합니다. |
| `show_list()` / `show_by_category()` | 전체 목록 또는 선택한 카테고리의 목록을 보여줍니다. |
| `search_prompts()` | 제목 또는 내용에서 키워드를 검색합니다. |
| `show_detail()` | 번호로 선택한 프롬프트의 전체 내용과 조회수를 표시합니다. |
| `toggle_favorite()` / `show_favorites()` | 즐겨찾기 상태를 변경하거나 즐겨찾기 목록을 보여줍니다. |
| `load_prompts()` / `save_prompts()` | `prompts.json` 데이터를 읽고 저장합니다. |
| `export_to_markdown()` | 카테고리별 Markdown 파일을 `exports/`에 생성합니다. |
| `edit_prompt()` / `delete_prompt()` | 프롬프트를 수정하거나 확인 후 삭제합니다. |
| `show_top_prompts()` | 조회수가 높은 순서로 프롬프트를 정렬해 보여줍니다. |

## 프로그램 설계

`run()` 함수는 `while True` 메인 루프로 메뉴를 반복 표시합니다. 각 메뉴 기능은 독립 함수가 처리한 뒤 다시 메뉴로 돌아가므로, 기능 간 흐름을 단순하게 유지할 수 있습니다. 사용자가 `0`을 선택했을 때만 `break`로 루프를 종료합니다.

프롬프트는 **리스트 안의 딕셔너리**로 관리합니다. 순서와 번호를 유지하기 쉽고, 제목·내용·카테고리·즐겨찾기·조회수처럼 속성이 다른 데이터를 한 항목으로 묶기 좋기 때문입니다. 현재 규모에서는 JSON 파일이 간단하고 사람이 읽기도 편합니다. 여러 사용자가 동시에 접근하거나 데이터가 크게 늘어난다면 SQLite 같은 데이터베이스가 더 적합합니다.

### 검색 방식과 한계

- 제목 또는 내용에 검색어가 **부분 일치**하면 결과에 포함됩니다.
- 제목·내용·검색어를 모두 소문자로 바꿔 비교하므로 영문 대소문자를 구분하지 않습니다.
- 형태소 분석, 오타 보정, 유사어 검색, 검색어 순위 계산은 제공하지 않습니다.

### 동명 프롬프트와 내보내기 규칙

- 같은 제목의 프롬프트를 여러 개 등록할 수 있습니다. 제목으로 덮어쓰지 않으며, 목록 번호로 각각 구분합니다.
- Markdown 내보내기는 카테고리당 하나의 파일을 만듭니다. 같은 카테고리를 다시 내보내면 해당 파일은 최신 전체 목록으로 **덮어써 갱신**됩니다.

## Git 작업 방식

`main`은 동작하는 통합 브랜치로 유지하고, 독립 기능은 `feature/기능명` 브랜치에서 구현한 뒤 검증·커밋하고 `main`으로 병합합니다. 예를 들어 목록 기능은 `feature/prompt-list`, JSON 기능은 `feature/json-persistence`에서 작업했습니다.

커밋은 기능 단위로 나눕니다. 한 커밋에는 한 가지 의도가 드러나도록 하고 아래 접두어를 사용합니다.

```text
feat: 새 기능 추가
fix: 오류 수정
docs: README·문서 수정
chore: 개발 환경·보조 파일 변경
merge: 기능 브랜치 병합
```
